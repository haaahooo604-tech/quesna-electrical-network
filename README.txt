منصة المعهد الفني الصناعي بقويسنا - الفرقة الثانية شعبة شبكات كهربائية
تصميم وإدارة: محمد سامح

محتويات المجلد:
1. index.html : الصفحة الرئيسية للمنصة (الجدول، التسجيل والسيرة الذاتية، المواد السبع، قائمة الطلاب، الدعم الفني، ولوحة الأدمن).
2. style.css  : ملف التنسيق والألوان الهندسية.
3. app.js     : ملف البرمجة وربط قاعدة بيانات Firestore لمشروع (second-year-networks).

طريقة التشغيل والنشر:
1. فك الضغط عن الملف المضغوط على جهازك.
2. افتح ملف app.js وضع قيم messagingSenderId و appId من إعدادات مشروعك في Firebase (Project settings -> Your apps).
3. لفتح المنصة محلياً: اضغط مرتين على ملف index.html.
4. لنشر المنصة برابط للطلاب: ارفع المجلد كاملاً على Netlify Drop (app.netlify.com/drop) أو GitHub Pages.
